# 강아지 건강식 만들기 설정

## 사용자와 목표
- 사용자: 강아지에게 건강식을 주고싶은 사람
- 목표: 강아지에게 필요한 영양소를 확인하고 레시피를 확인한다. 

## 사용자의 흐름
1. 강아지 정보(나이, 성별, 몸무게, 알러지 여부 등)를 입력한다. 
2. 강아지에게 필요한 영양소를 확인한다. 
3. 영양소 공급을 위한 건강식 레시피를 확인한다.
4. 건강 레시피 구독 여부를 설정한다. 
5. 설정 완료 안내를 확인하고, 필요하면 다시 설정한다. 

## 인터랙션 시나리오
1. 시작과 개인정보 활용 동의 안내
- 행동, 이벤트: 기존 동의 체크박스를 선택하고 '시작하기'를 클릭한다.
- 조건: 개인정보 활용 동의가 선택되었는가?
- 반응, 다음 상태: 동의 전에는 버튼을 누를 수 없다. 동의 후 클릭하면 사용 목적을 안내하는 팝업이 열린다. 팝업에서 '돌아가기'를 누르거나 esc를 누르면 동의를 해제하고 시작 화면에 남는다. '동의하고 시작하기'를 누르면 강아지 정보 입력 화면을 연다.
2. 강아지 정보 입력
- 행동, 이벤트: 강아지 정보를 입력하고 '레시피 선택하기'를 클릭한다. 
- 조건: 앞뒤 공백을 지운 강아지 정보란이 비어 있는가?
- 반응, 다음상태: 비어있으면 같은 화면에 오류를 표시하고 입력창에 초점을 둔다. 
            값이 있으면 저장하고 레시피 선택으로 이동한다. 
3. 필수 영양소 확인 후 원하는 레시피 선택
- 행동, 이벤트: 레시피를 선택하고 '레시피 설정'을 클릭한다. 
- 조건: 레시피를 선택했는가?
- 반응, 다음상태: 선택했을 때만 단계별 상세 레시피를 보여준다. 
4. 내용 확인
- 행동, 이벤트: 강아지 정보, 레시피 선택 내용을 읽고 '수정하기' 또는 '완료하기'를 클릭한다. 
- 조건: 수정인가, 완료인가?
- 반응, 다음상태: 수정하면 기본 값을 유지하고 조건 선택으로 돌아간다.
            완료하면 완료 안내로 이동한다. 
5. 완료와 다시 설정 
- 행동, 이벤트: 완료 안내를 읽고 필요하면 '다시 설정하기'를 클릭한다. 
- 반응, 다음상태: 새 설정의 강아지 정보, 레시피 선택을 초기화하고 강아지 정보 입력부터 다시 시작한다. 이미 확인한 개인정보 활용 동의와 다른 기능을 유지한다. 


# 중간고사 

# 강아지 건강식 만들기 및 맞춤 레시피 추천 서비스

## 1. 신규 추가 기능
기존 7주차에 구현한 반려견 기본 정보 입력 및 수정 흐름(다단계 폼)에 이어, 메인 화면 그리드의 빈 영역에 반려견의 식단 고민에 따른 '맞춤 건강 레시피 빠른 조회' 기능을 새로 구현했습니다.  
사용자가 식단 고민(체중 감량, 저자극 알레르기 케어, 원기 회복)을 선택하면, 조건에 맞춘 추천 요리와 핵심 조리 특징이 화면에 동적으로 안내됩니다.

## 2. 사용자와 목표
- 사용자: 반려견에게 알맞은 건강식을 제공하고 식단 고민(체중, 알레르기, 기력)을 해결하고 싶은 보호자
- 목표: 복잡한 레시피 확인 전, 반려견의 식단 고민에 적합한 추천 레시피와 핵심 영양 특징을 빠르게 확인한다.


## 3. 사용자의 흐름
1. 메인 대시보드의 '맞춤 레시피 빠른 조회' 카드를 확인한다.
2. 식단 고민 목록(체중 감량, 알레르기 케어, 원기 회복) 중 하나를 선택한다.
3. '추천 식단 확인하기'를 클릭하여 맞춤 레시피 결과를 확인한다.
4. 추천 식단 확인 후 필요에 따라 다른 옵션을 다시 조회한다.

## 4. 인터랙션 시나리오

### ① 식단 고민 선택 및 레시피 조회
- 행동, 이벤트: 셀렉트 박스에서 원하는 식단 고민을 선택하고 '추천 식단 확인하기' 버튼을 클릭한다.
- 조건: 식단 고민 옵션을 실제로 선택했는가? (기본값인 `-- 고민 선택 --` 상태인지 검사)
- 반응, 다음 상태:
  - 미선택 시: "식단 고민을 목록에서 선택해 주세요."라는 오류 문구를 표시하고, 선택창에 오류 스타일(`has-error`)을 적용하며 결과창을 숨긴다.
  - 선택 완료 시: 오류 문구를 제거하고 하단 결과 박스를 표시한다. 선택한 조건에 따라 맞춤 식단 이름과 설명(체중 감량: 단호박 닭가슴살 찜 / 알레르기: 오리고기 연근볼 / 원기 회복: 소고기 황태죽)을 동적으로 보여준다.

### ② 옵션 변경 및 재조회
- 행동, 이벤트: 표시된 추천 레시피를 확인한 뒤 다른 식단 고민으로 변경하고 다시 '추천 식단 확인하기'를 클릭한다.
- 조건: 변경된 옵션 값이 유효한가?
- 반응, 다음 상태: 페이지 새로고침 없이 하단 결과 박스의 레시피 이름과 설명이 새로 고른 고민에 맞춰 즉시 갱신된다.

5. 테스트 기록 (직접 시험 결과)

- 정상 경로 (성공) | '체중 감량' 선택 후 [추천 식단 확인하기] 클릭 | '단호박 닭가슴살 찜' 식단 안내 카드 표시 | 결과 박스가 열리며 레시피 이름과 설명이 정상 출력됨 | 통과 |
- 정상 경로 (옵션 변경) | '알레르기 케어'로 옵션 변경 후 다시 클릭 | 결과 박스의 내용이 '저자극 오리고기 연근볼'로 즉시 변경 | 선택 옵션에 맞춰 화면 내용이 동적으로 갱신됨 | 통과 |
