# 강아지 건강식 만들기 설정

## 사용자와 목표
- 사용자: 강아지에게 건강식을 주고싶은 사람
- 목표: 강아지에게 필요한 영양소를 확인하고 레시피를 확인한다. 

## 사용자의 흐름
1. 강아지 정보(나이, 성별, 몸무게, 알러지 여부 등)를 입력한다. 
2. 강아지에게 필요한 영양소를 확인한다. 
3. 영양소 공급을 위한 건강식 레시피를 확인한다.
4. 건강 레시피 구독 여부를 설정한다. 
5. 설정 완료 안내를 확인하고, 필요하면 다시 설정한다. 

## 인터랙션 시나이로
1. 시작과 개인정보 활용 동의 안내
- 행동, 이벤트: 기존 동의 체크박스를 선택하고 '시작하기'를 클릭한다.
- 조건: 개인정보 활용 동의가 선택되었는가?
- 반응, 다음 상태: 동의 전에는 버튼을 누를 수 없다. 동의 후 클릭하면 사용 목적을 안내하는 팝업이 열린다. 팝업에서 '돌아가기'를 누르거나 esc를 누르면 동의를 해제하고 시작 화면에 남는다. '동의하고 시작하기'를 누르면 강아지 정보 입력 화면을 연다.
2. 강아지 정보 입력
- 행동, 이벤트: 강아지 정보를 입력하고 '레시피 선택하기'를 클릭한다. 
- 조건: 앞뒤 공백을 지운 강아지 정보란이 비어 있는가?
- 반응, 다음상태: 비어있으면 같은 화면에 오류를 표시하고 입력창에 초점을 둔다. 
            값이 있으면 저장하고 레시피 선택으로 이동한다. 
3. 필수 영양소 확인 후 원하는 레시피 선택
- 행동, 이벤트: 레시피를 선택하고 '레시피 설정'을 클릭한다. 
- 조건: 레시피를 선택했는가?
- 반응, 다음상태: 선택했을 때만 단계별 상세 레시피를 보여준다. 
4. 내용 확인
- 행동, 이벤트: 강아지 정보, 레시피 선택 내용을 읽고 '수정하기' 또는 '완료하기'를 클릭한다. 
- 조건: 수정인가, 완료인가?
- 반응, 다음상태: 수정하면 기본 값을 유지하고 조건 선택으로 돌아간다.
            완료하면 완료 안내로 이동한다. 
5. 완료와 다시 설정 
- 행동, 이벤트: 완료 안내를 읽고 필요하면 '다시 설정하기'를 클릭한다. 
- 반응, 다음상태: 새 설정의 강아지 정보, 레시피 선택을 초기화하고 강아지 정보 입력부터 다시 시작한다. 이미 확인한 개인정보 활용 동의와 다른 기능을 유지한다.
